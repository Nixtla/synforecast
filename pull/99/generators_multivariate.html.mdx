### `CopulaGenerator`

Bases: <code>[BaseGenerator](#synforecast.base.BaseGenerator)</code>

Generate correlated time series using Gaussian or t copulas.

Copulas model the dependence structure between variables independently
of their marginal distributions. Sampling proceeds in two steps:

1. Draw correlated uniforms from the copula. Gaussian copula:
   ``z ~ N(0, R)``, ``u_i = Phi(z_i)``. t copula: ``z ~ N(0, R)``,
   ``w ~ chi2(df)``, ``u_i = T_df(z_i * sqrt(df / w))`` (the chi-square
   mixing is shared across variables, which creates tail dependence).
2. Map each uniform through the inverse CDF of its marginal:
   ``x_i = F_i^{-1}(u_i)``.

For the Gaussian copula the rank correlations satisfy
``spearman = (6 / pi) * arcsin(rho / 2)`` and for both copulas
``kendall_tau = (2 / pi) * arcsin(rho)``.

``generate(n_series)`` creates ``n_series`` correlated variables sharing
one length; each variable is one ``unique_id`` in the long-format output.
Samples are i.i.d. over time (no serial dependence).

### `VARGenerator`

Bases: <code>[BaseGenerator](#synforecast.base.BaseGenerator)</code>

Generate correlated time series using a Vector Autoregression model.

A VAR(p) process models each variable as a linear function of past
values of all variables:

```
y[t] = c + A_1 y[t-1] + ... + A_p y[t-p] + e[t],  e[t] ~ (0, Sigma)
```

The process is stable (stationary) iff the companion matrix

```
[[A_1 ... A_p], [I 0 ... 0], ..., [0 ... I 0]]
```

has spectral radius &lt; 1, in which case the stationary mean is
``(I - A_1 - ... - A_p)^{-1} c``. Innovations are drawn from the
configured innovation distribution and correlated via the Cholesky
factor of Sigma. A burn-in of 100 steps is discarded.

``generate(n_series)`` creates ``n_series`` correlated variables sharing
one length; each variable is one ``unique_id`` in the long-format output.

**Parameters:**

---- | ---- | ----------- | -------
`min_length` | <code>[int](#int)</code> | Minimum length of each series. | *required*
`max_length` | <code>[int](#int)</code> | Maximum length of each series. | *required*
`freq` | <code>[str](#str) \| [int](#int)</code> | Frequency of the data. A pandas offset alias (e.g. 'D', 'h', '5min', 'MS') or an integer time index step. | *required*
`lag_order` | <code>[int](#int)</code> | VAR lag order p (default: 1). | *required*
`coef_matrices` | <code>[list](#list)[[list](#list)[[list](#list)[[float](#float)]]] \| None</code> | One square coefficient matrix per lag, all the same size. Must define a stable VAR. When None, random stable coefficients are generated. When sized differently from n_series, the leading principal submatrices are used (or zero-padded). | *required*

### `VARXGenerator`

Bases: <code>[VARGenerator](#synforecast.generators.var.VARGenerator)</code>

Generate a VAR panel driven by exogenous regressors with known effects.

Extends :class:`VARGenerator` with three kinds of regressors, each a
unit-variance AR(1) with coefficient ``exog_persistence``:

- shared (``exog_shared_k``): one value per period for every series, such
  as a promotion calendar; series ``i`` responds with effect
  ``shared_effects[i, k]``;
- future-known (``exog_future_k``): one value per series and period, known
  for the forecast periods, such as a plan or price; it moves its own
  series and, with ``exog_cross_scale > 0``, the other series;
- history-only (``exog_hist_k``): one value per series and period, known
  up to the forecast origin, such as an order book; it moves the series
  one period later.

Lag matrices are random with a configurable structure unless
``coef_matrices`` is given: ``"dense"`` (as ``VARGenerator``),
``"sparse"`` (each off-diagonal entry nonzero with probability
``sparsity``) or ``"groups"`` (every series responds to its own lag and to
the lagged total of each of ``n_groups`` groups). All are rescaled to a
stable process. With ``n_groups``, series ``i`` belongs to group
``i * n_groups // n_series`` and ``group_col`` holds it.

After :meth:`generate` (or :meth:`generate_values`), :attr:`truth`
returns the coefficients of that draw and its oracle forecast.

**Parameters:**

Name | Type | Description | Default
---- | ---- | ----------- | -------
`n_shared_exog` | <code>[int](#int)</code> | Shared regressors (default: 0). | *required*
`n_future_exog` | <code>[int](#int)</code> | Future-known regressors per series (default: 1). | *required*
`n_hist_exog` | <code>[int](#int)</code> | History-only regressors per series (default: 0). | *required*
`exog_persistence` | <code>[float](#float)</code> | AR(1) coefficient of every regressor in [0, 1) (default: 0.5). | *required*
`exog_scale` | <code>[float](#float)</code> | Standard deviation of the shared effects and of a regressor's effect on its own series (default: 1.0). | *required*
`exog_cross_scale` | <code>[float](#float)</code> | Standard deviation of the total effect of the other series' regressors on one series; each entry has standard deviation ``exog_cross_scale / sqrt(n_series - 1)`` (default: 0.0, own effects only). | *required*
`cross_structure` | <code>[str](#str)</code> | Random lag structure: 'dense', 'sparse' or 'groups' (default: 'dense'). | *required*
`sparsity` | <code>[float](#float)</code> | Probability that an off-diagonal lag coefficient is nonzero under 'sparse' (default: 0.1). | *required*
`n_groups` | <code>[int](#int) \| None</code> | Number of contiguous series groups; required for 'groups' (default: None). | *required*
`group_col` | <code>[str](#str)</code> | Column holding the group of each series (default: 'group'). | *required*

### `VARXTruth`

```python
VARXTruth(lag_matrices, intercept, shared_effects, future_effects, hist_effects, innovation_covariance, exog_persistence, groups)
```

The process behind one ``VARXGenerator`` draw.

Shapes use ``N`` series, ``p`` lags and ``S``/``F``/``H`` shared, future-known
and history-only regressors::

```
y[t] = intercept + sum_l lag_matrices[l] @ y[t - 1 - l]
       + shared_effects @ shared[t]
       + sum_k future_effects[k] @ future[t, :, k]
       + sum_k hist_effects[k] @ hist[t - 1, :, k] + e[t]
```

Every regressor is a unit-variance AR(1) with coefficient
``exog_persistence``. ``groups`` holds the group of every series (None
without ``n_groups``). The truth describes the process before missing
data, anomalies and changepoints are injected.

#### `VARXTruth.forecast`

```python
forecast(y, shared, future, hist, h)
```

Conditional-mean forecast ``(h, N)`` after the last row of ``y``.

The optimal squared-error forecast of the process, an oracle for
benchmarking estimators. ``y`` is the history ``(T, N)`` with
``T >= p``; ``shared`` ``(h, S)`` and ``future`` ``(h, N, F)`` hold the
future-known regressors of the forecast periods; ``hist`` ``(N, H)``
holds the history-only regressors at the last period, whose later values
are replaced by their AR(1) expectation.


### `GaussianProcessGenerator`

Bases: <code>[BaseGenerator](#synforecast.base.BaseGenerator)</code>

Generate time series by sampling from a Gaussian Process.

Samples ``f ~ GP(mean, k)`` on the integer grid t = 0..length-1, so the
marginal distribution is ``N(mean, amplitude^2 + noise_variance)`` and
the correlation at lag r is ``k(r) / k(0)``.

Kernels (r = |t - t'|, l = length_scale, a = amplitude):
    - rbf: ``a^2 exp(-r^2 / (2 l^2))`` — infinitely differentiable,
      very smooth paths
    - matern_0.5: ``a^2 exp(-r/l)`` — rough, Ornstein-Uhlenbeck-like
    - matern_1.5: ``a^2 (1+s) exp(-s)``, s = sqrt(3) r / l —
      once-differentiable
    - matern_2.5: ``a^2 (1+s+s^2/3) exp(-s)``, s = sqrt(5) r / l —
      twice-differentiable
    - periodic: ``a^2 exp(-2 sin^2(pi r / period) / l^2)`` — exact
      periodicity

The periodic kernel is sampled exactly: one period by circulant FFT for an
integer period up to ``4 * max(length, 1024)``, otherwise its cosine
series, or Durbin-Levinson for very short length scales. The other kernels
use FFT circulant embedding.

**Parameters:**

Name | Type | Description | Default
---- | ---- | ----------- | -------
`kernel` | <code>[str](#str)</code> | Kernel type (default: 'rbf'). | *required*
`length_scale` | <code>[float](#float)</code> | Kernel length scale (default: 20.0). | *required*
`amplitude` | <code>[float](#float)</code> | Signal amplitude / output scale (default: 1.0). | *required*
`period` | <code>[float](#float)</code> | Period for the periodic kernel (default: 50.0). | *required*
`mean` | <code>[float](#float)</code> | Mean function value (default: 0.0). | *required*
`noise_variance` | <code>[float](#float)</code> | Variance of independent observation noise added to each point (default: 1e-6). | *required*
